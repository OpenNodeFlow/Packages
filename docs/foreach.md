# Native For Each packages

Balena 1.1.0 adds nine pure singular-resource Fields nodes while retaining every 1.0.0 definition and indexed List Item helper unchanged. Fields nodes reuse the existing named resource types, validate/project known fields, preserve null and absence, and perform no I/O. NetBird 2.7.0 retains the entire 2.6.0 release and adds documentation revisions to its existing API and singular-object Decode nodes; code, ports, types, metadata, ingress and provider behavior stay unchanged. No new bulk endpoints, provider dependencies or manifest fields exist.

Requires V2's native `GraphNode.forEach={input,concurrency,errorMode,maxItems}`. This setting belongs to the saved node instance. Select one singular scalar/custom-object input. Supply an array to that input; other inputs/config are broadcast. Default concurrency 1, errorMode stop, maxItems 1000; caps 16 and 10000. Data outputs gather in original index order. Collect-mode failed items occupy null positions with `{index,message}` entries in `__foreachErrors`; handle failures before passing IDs to another action. Optional missing outputs also become null, so consult the error indices. Routes fire once after collection, not once per item. Empty input performs no provider calls. Keep retries disabled; stop cannot undo concurrent provider effects. Original definitions still execute once per item, with original contracts and identity.

Balena: `List Devices.items -> Device Fields.item [For Each: item] -> id[] -> Get Device.id [For Each: id]`. For confirmed write nodes, broadcast the deliberate `confirm=true` and other reviewed inputs/config; there is one request per started item. Saved encrypted secret references are unchanged. Existing indexed List Item nodes continue supporting ordinary single-item selection.

NetBird: `List Peers.items -> NetBird Peer Batch Decode.value [For Each: value] -> id[] -> NetBird Get Peer.peerId [For Each: peerId]`. List Peers returns the Peer Batch variant, distinct from Get Peer's full Peer type. Groups, Networks and Policies use their existing exact singular decoders. For Get Network Router/Resource, iterate `routerId`/`resourceId` and broadcast one `networkId`. An operation's existing list-valued argument (for example Create Group.peers) is a single intentional membership collection. Do not select it as one independent mutation per member.

Balena paging remains explicit, bounded to one requested page. Native For Each on a list operation gathers nested lists; it does not flatten them or traverse provider pages. Existing NetBird poll/profile requirements and finite-response bounds stay unchanged. No installed workflow, provider call, subscription, profile, deployment or ONF package installation is performed by publication.
